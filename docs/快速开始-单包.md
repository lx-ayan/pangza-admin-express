# @pangza/express 单包：安装与发布

对应清单 **P0**：先发可用的单包，多包 / CLI 后续再做。

---

## 维护者：打可发布包

在仓库根目录：

```bash
npm run build:lib
```

产物目录：`packages/pangza-express/`（含 `index.js`、`index.d.ts`、生成的 `package.json`）。

本地试打包：

```bash
cd packages/pangza-express
npm pack --dry-run
# 确认无误后
npm publish --access public
```

需已登录 npm，且有权发布 scope `@pangza`（或把 `package.json` 里的 `name` 改成你的包名）。

## 用户：脚手架（推荐）

```bash
npx create-pangza init my-app
# 或: npm create pangza@latest -- init my-app
cd my-app
cp .env.example .env
npm install
npm run dev
```

`init` 会生成**空模板**，交互勾选模块：`orm` / `auth` / `redis` / `log` / `schedule` / `encrypt` / `validate`。  
非交互：`npx create-pangza init my-app --modules=orm,redis --db=mysql`  

Redis / 数据库**按需启用**：只有 `Application.registry(EnableRedis())` / `EnableOrm()`（或 Auth 绑定了 redis）时才会在启动时预热连接；未注册则不会因缺配置报错。  

**拦截器**（自定义请求/响应，可跳过 `ResponseData`）：

```ts
Application.addRequestInterceptor(async ({ req }) => {
  // 鉴权/限流之后、Controller 之前
});

Application.addResponseInterceptor(async (ctx) => {
  // 默认会包装 ResponseData.success；自定义外层时：
  ctx.wrap = false;
  return { code: 0, result: ctx.data };
  // 或自行 ctx.res.json(...); ctx.handled = true;
});
```  

生成业务文件（在项目目录内）：

```bash
npx create-pangza g controller user
npx create-pangza g all user          # entity + mapper + service + controller
# 别名: c|cotroller / s / m / e / a ；覆盖加 --force
```

脚手架源码：仓库根目录 `create-pangza/`。

## 用户：手动安装

```bash
npm i @pangza/express express reflect-metadata inversify
# 按需
npm i mysql2 redis cors
```

`tsconfig.json` 需开启：

```json
{
  "compilerOptions": {
    "experimentalDecorators": true,
    "emitDecoratorMetadata": true
  }
}
```

入口最上方：`import "reflect-metadata";`

---

## 用户：最小代码

```ts
import "reflect-metadata";
import { Application, Controller, GetMapping, Logger } from "@pangza/express";
import { json } from "express";
import cors from "cors";

@Controller("/api/hello")
class HelloController {
  @GetMapping("/")
  hello() {
    return { ok: true };
  }
}

Application.registry(Logger({ level: "info" }))
  .registry(cors())
  .registry(json())
  .scan("src")
  .start();
```

## 仓库内联调（不发 npm）

```bash
# 1. 先打库
npm run build:lib

# 2. 安装示例依赖（指向本地 packages/pangza-express）
cd examples/starter
npm install
npm run dev
```

浏览器或 curl：`GET http://127.0.0.1:5270/api/hello/`（端口以 `.env` / 默认配置为准）。
