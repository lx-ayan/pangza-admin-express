### 三阶段开发

1. 数据库支持多数据源 ✅
2. ORM 操作支持多个库（MySQL / PostgreSQL / SQL Server），Mapper / QueryWrapper 共用；`@Select` / `@Insert` 等可指定库 ✅
3. ORM `@TableId` 补充 ID 类型（对齐 MyBatis-Plus `IdType`）✅
4. `@Bean` 装饰器，结合 `@Component`，返回值可注入容器 ✅

---

#### 1–2 已实现说明

**多数据源**

- `Db.register(name, { type, host, ... })` 注册命名数据源
- 默认源名 `"default"`，来自 `DB_TYPE` + `MYSQL_*` / `DB_*`
- 设置 `PG_HOST` / `MSSQL_HOST` 时自动注册 `"postgresql"` / `"sqlserver"`
- `Db.queryOn(name, sql, params)` / `Db.transactionOn(name, fn)`

**多库方言（同一套 Mapper API）**

- `Dialect`：引号、`?`→`$n`/`@pN`、LIMIT/OFFSET、列清单、INSERT 回填 id
- `@Mapper(Entity, { datasource: "postgresql" })` / `table("user", { datasource: "pg" })`
- `QueryWrapper` 按方言引用列名

**定制 SQL 指定库**

```ts
@Select("SELECT * FROM user WHERE id = #{id}")  // 默认 default
@Select('SELECT * FROM "user" WHERE id = #{id}', { db: "postgresql" })
@Insert("INSERT INTO t(name) VALUES(#{name})", { datasource: "sqlserver" })
@Transactional({ datasource: "postgresql" })
```

`datasource`（名称）优先于 `db`（按类型查找唯一已注册源）。

#### 3 IdType

```ts
import { IdType, TableId, TableName } from "@/framework";

@TableName("order")
class OrderEntity {
  @TableId({ type: IdType.ASSIGN_ID })
  id!: string;

  // @TableId({ type: IdType.AUTO })      // 库自增（默认全局）
  // @TableId({ type: IdType.ASSIGN_UUID })
  // @TableId({ type: IdType.INPUT })     // 自行赋值
}
```

| IdType | 行为 |
|--------|------|
| `AUTO` | 数据库自增；插入后回写实体 |
| `NONE` | 跟随全局 `ORM_ID_TYPE` / `configureOrm({ idType })`（全局默认 `ASSIGN_ID`） |
| `INPUT` | 框架不生成 |
| `ASSIGN_ID` | 空则雪花 ID（string，避免精度丢失） |
| `ASSIGN_UUID` | 空则 32 位无横线 UUID |

可 `setIdentifierGenerator({ nextId, nextUUID })` 自定义生成器。

**DX 默认（降低业务样板）**

- 查询结果默认驼峰：`ORM_MAP_UNDERSCORE_TO_CAMEL=true`（可关）
- 全局逻辑删除默认开：`ORM_LOGIC_DELETE=true` → `@Mapper(Entity)` 即可
- insert 无需手写 `nextId()`，由 `ASSIGN_ID` 自动生成并回写实体

#### 4 @Bean

```ts
@Component()
class AppBeans {
  @Bean(ObjectMapper)
  objectMapper() {
    return new ObjectMapper();
  }

  @Bean("uploadPath")
  uploadPath() {
    return "/data/upload";
  }
}

// 注入
@Resource(ObjectMapper) private mapper!: ObjectMapper;
@Resource("uploadPath") private path!: string;
```

- `@Bean` 必须写在 `@Component` 类的方法上
- Token：类 / 字符串 / Symbol；省略则用方法名字符串
- `@Resource` / `Container.get` / `@Inject` 均可按 Token 获取
